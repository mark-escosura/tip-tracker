# Tip Tracker

Private, offline tip tracker PWA for iPhone. Open in Safari → Share → Add to Home Screen.

- All data lives in this browser's localStorage. No accounts, no analytics, no network requests at runtime.
- Back up with **Export CSV**; restore with **Import CSV** (merges, skips duplicates).
- 3D dashboard: three.js r186 (MIT), GSAP + ScrollTrigger (GSAP standard license), Lenis (MIT), all vendored locally.
